# NEWR Adventure Admin

Bot staff buat ngatur NEWR Adventure, khusus server NEWR LABS. Semua
command slash, semua khusus Administrator, member biasa selalu ditolak.

Satu database sama bot Adventure (`rpg.db`), jadi gold, item, pet, dan
pemain yang diubah di sini langsung kelihatan di bot pemain. Tapi ini
aplikasi Discord yang beda, token dan prosesnya sendiri.

Command: `/admin_help`, `/admin_event`, `/admin_rules`,
`/admin_currency`, `/admin_give`, `/admin_giveaway`, `/admin_player`,
`/admin_stats`, `/admin_announce`, `/admin_season`,
`/admin_achievement`.

Satu catatan: setting event, rate, dan ban dari bot ini kesimpan rapi
di tabel admin, tapi baru berlaku penuh di bot Adventure setelah patch
yang didokumentasikan di SETUP.md. Bot ini sengaja nggak ngubah bot
Adventure sendiri.
